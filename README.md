# My To-do List

A lightweight, responsive to-do list application that stores tasks in the browser's `localStorage`.

## Use

Open `index.html` in a modern browser. Add tasks, mark them complete, filter the list, delete individual tasks, or clear all completed tasks. Your list is saved automatically in this browser on this device and remains available after you close or reload the page.

No account, server, or network access is required. Clearing browser site data removes the saved tasks.
